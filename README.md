# AI 办公与工具合集（持续更新）

AI 工具最难的不是找到一个，是知道哪件事该交给哪个工具：写公众号、追热点、做招聘、处理表格 PPT，每件事都有人已经跑通了整套流程，散着找要翻几十个帖子，还分不清是演示还是能落地的。这里把内容运营、日常办公和用 AI 做产品这三条线的主流课程与工具按用途整理好，每条都附内容清单和获取入口，点开先看目录，确认对得上自己的活儿再转存。

## 内容生产与运营

- **AI 自动化公众号运营 · 打造可持续的 AI 内容工作台**
  公众号最熬人的是日更：选题、写稿、排版、发布全靠一个人硬扛。这套讲的是把运营流程和工具配置搭成一个能持续转的工作台，从选题到发布形成流水线，适合一个人运营、又不想断更的自媒体人。
  → https://openpan.cc/resource/1633

- **热点写作工具（自动抓热点 + 写文章 + 多平台发布）**
  追热点慢一步就没流量，手动刷热点、再写稿、再逐个平台发，一篇文章大半天没了。这个工具自动抓取全网热点、生成文章并排版、一键多平台发布，本体在 GitHub 有 2.5K Stars，含工具本体与使用说明，适合需要批量出稿的内容团队先拿去跑一遍流程。
  → https://openpan.cc/resource/1634

## 职场办公提效

- **14 天 ChatGPT 赋能 HR 业务提效训练营**
  HR 的时间大多耗在重复文字活上：JD、面试题、通知、培训材料一写就是半天。这门课专对 HR 岗位，覆盖招聘、面试、培训等场景的提示词与工作流，14 天按场景拆着练，学完能直接套到手头工作里，不用自己从零试提示词。
  → https://openpan.cc/resource/1635

- **Codex AI 智能办公系统实战课**
  文件堆成山、表格反复改、PPT 临时赶、日报周报每周重写——这些才是办公时间的大头。这套课用 Codex 处理文件、表格、PPT、项目管理、数据分析和企业日报，把重复事务做成自动化流程，适合想把 AI 真正用进日常办公、而不是只聊天问答的人。
  → https://openpan.cc/resource/1643
